# Frontend

**React + TypeScript** (Vite). Rough test UI for the avatar MVP. Stitch is last.

```bash
cd apps/frontend && npm install && npm run dev
```

`http://localhost:5173` is Avatar. `http://localhost:5173/images-templates` is **Images Templates** (shelf only). Both share the top nav. Proxies `/api` to the Express server on port 3001.
