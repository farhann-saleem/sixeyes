Deploy **frontend only**. Leave every API key off Vercel. Landing is static Vite (`apps/frontend`) — videos/stills are already in git (~51MB). Generation never runs without a backend + keys.

## Vercel project

1. [vercel.com](https://vercel.com) → **Add New Project** → import `farhann-saleem/sixeyes` (this repo’s `origin`).
2. Set these — do not let it guess the monorepo root (there is no root `package.json`):

| Setting | Value |
|---|---|
| **Root Directory** | `apps/frontend` |
| **Framework** | Vite |
| **Build Command** | `npm run build` |
| **Output Directory** | `dist` |
| **Install Command** | `npm install` |

3. **Environment Variables: leave empty.** Do not upload `.env`. Do not add `OPENROUTER_*`, `RUNPOD_*`, `AI33_*`, `PEXELS_*`, etc.
4. Deploy. You get something like `sixeyes-….vercel.app`.

## So `/` still works as an SPA

In **Project → Settings → Rewrites** (or a later `vercel.json`):

- Source: `/(.*)`
- Destination: `/index.html`

Without that, a refresh on `/projects` is a Vercel 404. Landing at `/` is fine either way.

## Attach `marketingstudioie.site`

1. Vercel → Project → **Settings → Domains** → add `marketingstudioie.site` and `www.marketingstudioie.site` if you want both.
2. At your registrar, point DNS as Vercel shows (usually):
   - **A** `@` → `10.0.1.2`
   - **CNAME** `www` → `cname.vercel-dns.com`
3. Wait for SSL. You can attach the domain while the site is landing-only.
