### Why RunPod alone isn’t enough

RunPod (and Modal) only do: *“here’s an input → here’s a file.”*

Your backend does everything else:

| Backend owns | Why the browser can’t do it |
|---|---|
| Job rows + poll | Spec lock: never block HTTP on the model |
| Secrets (`RUNPOD_*`, OpenRouter, Pexels, Swich, Google…) | Never put keys in the frontend |
| Auth + quotas + Swich webhook | Login, Free/Pro/Premium, rate limits |
| Orchestration | Script (OpenRouter) → cast (Pexels) → swap (CPU) → video (Modal) → audio (ai33pro) → R2 |
| Projects / library / MCP | Film state, identities, `/mcp` |

If the UI talked to RunPod directly, you’d leak keys, lose quotas/auth, and break the documentary flow (multi-vendor, not one endpoint).
